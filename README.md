# stefan-dopamine

Container repository for Stefan dopamine analysis projects.

## Projects

- `stim-exp-python/`: Python port of the stimulation experiment FIP preprocessing
  and heatmap/PSTH analysis.
- `syllables_analysis_datta/`: MATLAB preprocessing, syllable analysis, PSTH,
  trajectory, plot-player, and video GUI scripts for the Datta collaboration
  syllables workflow.
